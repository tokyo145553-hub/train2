# 運転見合わせ画像ジェネレーター（GitHub Pages対応） 以下の `index.html` をそのまま GitHub にアップロードすれば、 ブラウザ上で * 「運転再開見込み」の表示ON/OFF * 「○○の影響で」の文章変更 * 画像をワンクリックでコピー ができるようになります。 --- ```html 運行情報画像ジェネレーター

運行情報画像ジェネレーター

スマホでも利用可能 / GitHub Pages対応
``` --- # GitHub Pagesで公開する方法 1. GitHubで新しいリポジトリを作成 2. `index.html` をアップロード 3. 「Settings」→「Pages」 4. Branch を `main` に設定 5. Save 数十秒後に公開URLが発行されます。 --- # できること * 運転再開見込みの表示ON/OFF * 運転再開見込み時刻の変更 * 原因変更 * 信号装置故障 * 人身事故 * 車両故障 * 異音確認 など * 状態変更 * 運転見合わせ * 遅延 * 再開見込み変更 など * スマホ対応 * 画像コピー * PowerPoint貼り付け対応 --- # 追加済み仕様 すでにコード内には以下が実装されています。 ## 再開見込み ON/OFF ```html ``` チェックを外すと、 ```text 運転再開見込み：20時30分頃 ``` の表示が消えます。 --- ## 再開見込み時刻変更 ```html ``` ここを書き換えることで * 21時頃 * 未定 * 調査中 * まもなく再開見込み など自由に変更できます。 --- ## 表示ロジック ```javascript if(showResume){ ctx.fillStyle = '#fff'; ctx.font = '48px sans-serif'; ctx.fillText('運転再開見込み：' + resumeText, 450, 80); } ``` これにより、チェックONの時だけ表示されます。
